=============================================
  MediGuess — Медицинская образовательная игра
  Версия 1.0.0 | Сборка для Windows
=============================================

1. БЫСТРЫЙ ЗАПУСК (браузер)
---------------------------
Откройте папку "dist" и запустите файл "index.html" двойным кликом.
Игра откроется в браузере и будет полностью работоспособна.

2. СБОРКА EXE-ПРИЛОЖЕНИЯ (через Tauri)
--------------------------------------
Требования:
  - Windows 10/11
  - Node.js 18+   (https://nodejs.org)
  - Rust          (https://rustup.rs)

Шаги:
  1. Откройте командную строку (cmd) или PowerShell
  2. Перейдите в папку с проектом:
       cd DOC
  3. Установите зависимости:
       npm install
  4. Соберите приложение:
       npm run tauri:build

Результат:
  - EXE:  src-tauri\target\release\MediGuess.exe
  - MSI:  src-tauri\target\release\bundle\msi\*.msi
  - NSIS: src-tauri\target\release\bundle\nsis\*.exe

3. СТРУКТУРА ПРОЕКТА
--------------------
  dist/           — Готовая статическая сборка (открыть в браузере)
  src/            — Исходный код React + TypeScript
  src-tauri/      — Исходный код Rust для десктопного приложения
  public/data/    — JSON-файлы с медицинскими кейсами
  style.css       — Стили приложения
  index.html      — Точка входа
  vite.config.ts  — Конфигурация сборщика Vite
  package.json    — Зависимости Node.js

4. РЕЖИМЫ ИГРЫ
--------------
  - Ежедневный:    Новый кейс каждый день
  - Бесконечный:   Случайные кейсы без ограничений
  - Архив:         Просмотр и повторение всех кейсов
  - Ролевой:       Играйте за медсестру, интерна, хирурга и др.

5. ТЕХНОЛОГИИ
-------------
  Frontend:  React 18 + Vite + TypeScript + Zustand
  Desktop:   Tauri v2 (Rust)
  Стили:     Vanilla CSS

6. ЛИЦЕНЗИЯ
-----------
  Образовательный проект. Медицинский контент 16+.
  Не используйте для самодиагностики или самолечения.
